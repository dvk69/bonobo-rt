# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Project

Bonobo is a Python 3.5+ ETL (extract-transform-load) framework. The main package is `bonobo/`. Tests live in `tests/` mirroring the source layout. Build is managed via `Makefile` (generated by [medikit](https://github.com/python-medikit/medikit) — do **not** hand-edit the Makefile; edit `Projectfile` instead).

## Commands

```bash
# Install dev dependencies
make install-dev

# Run all tests
make test
# Equivalent: pytest --capture=no --cov=bonobo --cov-report html tests

# Run a single test file
pytest tests/config/test_configurables.py

# Run a single test by name
pytest tests/config/test_configurables.py::test_missing_required_option_error

# Format code (black + isort)
make format
```

## Code Style

- **Line length**: 120 characters (`black -l 120`, enforced by `.style.yapf` and `.editorconfig`)
- **Formatter**: `black` (primary) + `yapf` config in `.style.yapf` (pep8-based with `dedent_closing_brackets=true`)
- **Import sorting**: `isort` with `multi_line_output=5`; `mondrian` and `whistle` are treated as third-party (`-o mondrian -o whistle`)
- **`bonobo`** is the sole `known_first_party` package for isort

## Key Architectural Patterns

### Configurable / Option system
Nodes subclass [`Configurable`](bonobo/config/configurables.py) and declare fields using [`Option`](bonobo/config/options.py) descriptors. Constructing with missing required options returns a `PartiallyConfigured` (a `functools.partial`) rather than raising — instantiation is deferred until all options are provided. Use `_final=True` to force an error on missing options.

### ContextProcessor
[`@ContextProcessor`](bonobo/config/processors.py) is the only way to carry state across calls in a transformation. It's a generator-based setup/teardown pattern (yield once). Values yielded are injected as extra positional args to `__call__`.

### Special constants
- [`BEGIN`](bonobo/constants.py) — sentinel that marks graph entry points; all extractors connect from it
- [`NOT_MODIFIED`](bonobo/constants.py) — return from a transformation to pass input through unchanged
- [`EMPTY`](bonobo/constants.py) — alias for `()`, used to signal "no output"

### Error hierarchy
Subclass [`UnrecoverableError`](bonobo/errors.py) to signal errors that must stop the whole workflow. Plain exceptions only halt the current item. `AbstractError` is for abstract methods (raise via `raise AbstractError(self.method_name)`).

### Service injection
Use [`Service`](bonobo/config/services.py) option descriptor (not constructor injection) to declare external dependencies. Wire implementations at `bonobo.run()` time via the `services={}` dict. Default services `fs` (filesystem) and `http` (requests) are auto-populated by `create_container`.

### Public API surface
Everything exported from [`bonobo/_api.py`](bonobo/_api.py) and re-exported from [`bonobo/__init__.py`](bonobo/__init__.py) is the stable public API. Internal helpers live in `bonobo/util/`. The `bonobo.config` sub-package is also considered stable.

## Coverage

- Coverage omits `bonobo/examples/` and `bonobo/ext/` (see [`.coveragerc`](.coveragerc))
- Tests use `pytest-timeout`; tests touching execution are decorated `@pytest.mark.timeout(2)`
